# 命名考据

**定名（2026-10-27 终裁）：白泽 / baize，裸名，不加 OS 类后缀。**

- 本意 = 化身。名字命给「人」不命给机器：机身、引擎皆可换，白泽不变。
- 与**谛听（diting）**成对：谛听是耳（取材），白泽是心（记忆与人格）。
- 考据结论（出生时已毕，勿重查）：OS 命名空间无撞名；最近同名方是
  复旦白泽 Whitzard（AI 安全，同生态不同层，英文不用拼音）；其余皆
  远域。噪声认下，不构成冲突。
- **化身是种不是个体**：一台设备一个人，千千万万个白泽各长各的——
  「无处不在」=处处都有白泽这个种。
