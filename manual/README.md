# manual/ — 对人（主人树）

> 文档三树之一。对照 omacom `manual/`：给**人（主人）**看。
> 入口真源：本页。姐妹树：`AGENTS.md`（对 agent）、`docs/`（对系统）。

白泽的安装者是 agent，不是人。人对机器只出现在三处——其余步骤都在
对 agent 树里。

## 主人只做这三事

1. **递机器** — 把目标机接到工作台；确认串号（真源=你口头/纸条，永不入仓）。
2. **递秘密** — 按 agent 当面请示，一次手递 Wi-Fi / 密钥等；**不要**写进仓库、聊天记录或备份。
3. **收一句话汇报** — 机器名、装了什么、验了什么、缺什么。

刷 userdata / 毁数据类动作：必须你口头确认过备份，agent 才许动。

## 本树文件

| 件 | 说明 |
|----|------|
| `01-install.md` | 安装正典全文（读者=**agent**；人只读其中「递机器 / 递秘密 / 汇报」触点）。文件暂不搬家——归位上它挂在对 agent 索引下，对人树只摘三触点。 |

## 归位规则（硬）

| 可以写 | 不可以写 |
|--------|----------|
| 主人动作、确认项、收汇报的期望句式 | crate 名、Rust 路径、D 编号正文 |
| 「停手问主人」的人侧清单 | 烤链、`build-rootfs`、init.d、包频道内幕 |
| 指向对 agent / 对系统树的链接 | 把 `docs/DESIGN.md` 整段贴进手册 |

扩写本树时：先问「主人要不要亲手做」——不要，就写到 `AGENTS.md` 或 `docs/`。
